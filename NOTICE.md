### Provenance flag (open decision before store release)
Each record carries `prov`, taken from the upstream folder name:
`xm` (~2,500 TV remotes), `kk` (~1,300), `mx` (~140), `other` (~700).
The `kk`/`xm` naming matches the id style of commercial IR databases, so those
records may have been imported from third-party sources despite the MIT
licence on the repository. The release build can be restricted to
`prov == other` if we decide not to carry that risk.

## Not used
UberGuidoZ/Flipper-IRDB was used for the P0 prototype only and removed: its
CC0 licence covers contributions after commit 2319685 (Aug 2025), and 172 of
the 175 files we used pre-date it.
